# AsklyBux Task Bot

Professional Telegram earning/task bot built with Python, TeleBot, SQLite, and polling.

## Features

- User registration
- Wallet balance system
- Inline button UI
- Task list
- Random task/account assignment
- Persistent task lock system
- No duplicate assignment
- Verification code request
- Base32 2FA decoding
- Account submission flow
- Admin notification
- SQLite database
- Railway-ready deployment
- No Flask, no FastAPI, no external API, no webhook

## Tech Stack

- Python 3.11
- pyTelegramBotAPI
- SQLite3
- Base64/Base32 built-in decoding
- Polling
